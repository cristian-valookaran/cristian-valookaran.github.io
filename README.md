# Cristian Valookaran — Portfolio

Static, responsive portfolio for GitHub Pages.

## Publish / update

Upload the contents of this folder to the root of the GitHub Pages repository. Keep `index.html`, `styles.css`, `script.js`, `favicon.svg`, and the complete `assets/` folder together. For a personal site at `https://cristian-valookaran.github.io/`, the repository must be named `cristian-valookaran.github.io` and Pages should deploy from `main` / root.

To add or replace photographs, place the image in `assets/` and add a matching gallery `<figure>` in `index.html`. All current gallery images are original photographs supplied by Cristian; generated concept collages are intentionally not included as real portfolio photographs.
