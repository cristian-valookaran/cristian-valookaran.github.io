# Cristian Valookaran — Portfolio

A responsive, dark-editorial personal portfolio for a model and content creator.

## Preview locally
Open `index.html` in a browser. For best results, use a local server:
- `python -m http.server 8000`
- Visit `http://localhost:8000`

## Deploy to Vercel
1. Create a GitHub repository and upload the contents of this folder.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other**. Build command: leave empty. Output directory: `.`.
4. Deploy.
5. In Vercel project settings, add your custom domain when you have purchased it.

This is a static site: no build step or backend is required.

## Before sending to casting agencies
- Add a professional contact email and Instagram handle.
- Add clean digitals: front portrait, profile, full-length front and full-length side.
- Add chest, waist, hips, shoe size and other measurements only after confirming them.
- Keep AI-generated/editorial concept images separate from genuine casting digitals. The three current images are the supplied photographs.

## Updating the gallery
Put new images in `assets/`, then duplicate one `<figure class="gallery-item">...</figure>` block in `index.html` and update its image path, alt text and caption.
